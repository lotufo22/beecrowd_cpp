# 🐝 Beecrowd - Exercícios em C++

Repositório dedicado ao treino e resolução de exercícios da plataforma [Beecrowd](https://beecrowd.com/) (antigo URI Online Judge), com foco no desenvolvimento e aprimoramento da lógica de programação utilizando **C++**.

## 📌 Sobre o repositório

Este espaço reúne soluções para problemas de diferentes níveis de dificuldade, organizados por categoria. O objetivo principal é praticar constantemente, fixar conceitos fundamentais de programação e evoluir na resolução de problemas algorítmicos.

> 💡 Também mantenho um repositório irmão com exercícios resolvidos em **Java**, caso você queira comparar as abordagens entre as duas linguagens.

## 🎯 Objetivos

- Praticar lógica de programação de forma consistente
- Fortalecer conhecimentos em estruturas de dados e algoritmos
- Ganhar familiaridade com a sintaxe e recursos do C++
- Criar um histórico de evolução ao longo do tempo

## 📂 Estrutura do repositório

```
├── iniciante/
├── ad-hoc/
├── strings/
├── estruturas e biblitecas/
├── matematicas/
└── ...
```

Cada pasta contém os exercícios organizados por número/nome do problema, seguindo a numeração oficial da plataforma Beecrowd.

## 🚀 Como executar os códigos

```bash
# Compilar
g++ -o exercicio nome_do_arquivo.cpp

# Executar
./exercicio
```

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C++
- **Plataforma:** [Beecrowd](https://beecrowd.com/)

## 📈 Progresso

Este repositório é atualizado com frequência conforme novos exercícios são resolvidos. Sinta-se à vontade para acompanhar a evolução! 😄
